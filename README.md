# Flinks illustrations

Animated illustrations for Flinks web pages (native HTML/CSS/JS).

- `upload/` - Upload page animations (5)
- `gaming-lottery/` - Gaming & Lottery page animations (3)
- `cross-border-payments/` - Cross-Border Payments page animations (4)

Each animation: `<page>/<name>/embed/flinks-<name>.js` (single-file web component `<flinks-<name>>`).
